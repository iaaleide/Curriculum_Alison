# ALB Brasil — E-mails das Empresas

Planilha gerada a partir do arquivo de clientes ALB Brasil, com pesquisa de **e-mails públicos** das empresas.

## Entrega

Arquivo principal:

- [`/workspace/ALB_Brasil_Emails_Empresas.xlsx`](../ALB_Brasil_Emails_Empresas.xlsx)

## Conteúdo da planilha

| Aba | Conteúdo |
|---|---|
| 01_Resumo | Totais e guia de uso |
| 02_Todos_Contatos | 276 empresas únicas com telefone/site/e-mail |
| 03_Com_Email | Somente empresas com e-mail público encontrado |
| 04_Sem_Email | Empresas sem e-mail público (telefone/site mantidos) |
| 05_Por_UF | Consolidado por estado |
| 06_Nutricao_Frigorificos | Foco ração / frigorífico / players |
| 07_Lista_Disparo | Lista limpa para abordagem comercial |
| 08_Legenda | Critérios de confiança |

## Observações

- Grande parte de granjas, cerealistas e armazéns locais **não publica e-mail**; nesses casos o telefone da planilha original foi preservado.
- Confiança **Alta** = site/documento oficial da empresa.
- Validar contatos antes de disparos em massa (LGPD).
